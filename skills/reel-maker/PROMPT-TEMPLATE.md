# Template Prompt Reel

Salin blok di bawah ke Claude Code (buka di folder `claude-video`), ganti isi `[...]`, lalu kirim.
Kolom yang tidak mau diisi boleh dihapus, nanti Claude yang memutuskan.

---

```
Pakai skill reel-maker. Buat reel baru:

TOPIK      : [kenapa harus pakai AI di 2026]
PENONTON   : [karyawan & mahasiswa yang belum pakai AI]
POIN UTAMA : [3 alasan: hemat waktu, guru pribadi, peluang baru]
HOOK       : [Di 2026, orang yang pakai AI kerjanya jauh lebih cepat dari kamu.]
CONTOH     : [laporan seharian jadi 1 jam; belajar desain/coding dengan tanya AI]
CTA        : [Komen "AI" untuk daftar tools gratis]
DURASI     : [± 45 detik]
NADA       : [santai, sedikit provokatif, pakai "kamu" & "aku"]
SUARA      : [macOS Damayanti | ElevenLabs voice id: ...]
GAMBAR     : [pakai foto di reel/public/img/ | saya taruh foto baru: nama-file.jpg = ...]

Setelah render, cek out/<slug>-check.jpg, perbaiki kalau ada yang berantakan, lalu kirim path mp4-nya.
```

---

## Versi super singkat

```
Pakai skill reel-maker. Buat reel tentang: [ide kamu dalam satu kalimat]
```

```
Reel [slug]: [scene 3 ganti visual jadi compare / hook-nya kurang nendang / percepat suaranya]
```
